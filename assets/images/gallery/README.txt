HOW TO ADD REAL EVENT GALLERY PHOTOS:
=========================================
1. Put your event photos (JPEG/PNG) in this folder.
2. Open "js/data.js" and update the image paths in the GALLERY_EVENTS list.
   For example:
   image: "assets/images/gallery/hackathon-2024.jpg"
3. You can add as many new event photos as you want by appending items to the GALLERY_EVENTS list in "js/data.js"!
